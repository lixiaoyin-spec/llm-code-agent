# 任务：从零实现网页端贪吃蛇游戏

在本目录（demo/snake_game）从零实现一个可直接在浏览器游玩的贪吃蛇游戏（纯前端、无服务器），并补充单元测试。

## 功能规格

1. 文件结构：
   - index.html：页面入口（含棋盘画布或表格、分数显示、按键说明）
   - game.js：游戏核心逻辑 + 渲染与输入（逻辑与渲染必须分离，见"实现提示"）
   - style.css：页面样式（页面居中、棋盘清晰可见）
   - game.test.js：单元测试，使用 Node 内置的 node:test 与 node:assert，不引入任何第三方依赖
   - simulate.js：命令行模拟模式（验收用，见第 5 条）
2. 游戏规则（经典贪吃蛇）：
   - 棋盘 20x20 格（宽 x 高），四周有墙。
   - 蛇初始长度 3，位于棋盘中部，初始向右移动；食物随机出现在空白格。
   - 吃到食物：蛇身 +1、分数 +1，并立即生成新食物。
   - 撞墙或撞到自己：游戏结束，页面显示"游戏结束"与总分。
3. 交互（浏览器内）：
   - 方向键或 W/A/S/D 控制，方向不允许 180 度掉头。
   - 空格暂停/继续，R 重新开始；每 150ms 走一帧。
   - 分数实时显示在页面上方。
4. 逻辑与渲染分离（测试与验收的关键）：
   - 核心规则放在 `SnakeGame` 类（game.js 中），只负责状态与规则：`step(direction)` 返回本轮结果（是否吃到食物、游戏是否结束），`getBoard()` 返回棋盘二维数组。
   - game.js 用 CommonJS 导出核心逻辑（`if (typeof module !== "undefined") module.exports = {...}`），让 Node 测试、命令行模拟与浏览器页面使用同一份代码。
   - 食物生成可注入随机源（构造参数 seed），保证测试可重复。
5. 命令行模拟模式（验收必须）：
   - `node simulate.js <指令文件>`：读取指令文件（每行 right/left/up/down 或 r/l/u/d），逐帧把棋盘与分数打印到终端（帧间用空行分隔），游戏结束或指令用完即打印"游戏结束"与总分并正常退出（退出码 0）。
   - 模拟模式不清屏，便于查看输出。
6. 自测纪律（必须遵守）：
   - 只允许用 `node --test` 与 `node simulate.js demo_inputs.txt` 自测；禁止创建 debug*.js 之类的临时脚本。
   - 测试失败时先读报错与测试代码，理解原因后再修改 game.js；禁止不修改代码就重复运行同一命令。
   - 不要自己打开浏览器或启动服务器（本项目是纯静态页面）；完成后在总结中告诉用户用 `start index.html` 或双击 index.html 打开游玩。

## 实现提示（照做可避开绝大多数常见 bug）

- 蛇身坐标用数组保存，约定 `snake[0]` 是蛇头、`snake[snake.length - 1]` 是蛇尾；渲染时按此约定画蛇头/蛇身。
- 初始化：蛇头在 (10, 10)，蛇身向左延伸：`snake = [[10, 10], [9, 10], [8, 10]]`，初始方向 right（x 向右、y 向下）。
- `step(direction)` 按以下顺序实现：
  1. 若新方向与当前方向相反（right 对 left、up 对 down），忽略该指令，保持原方向继续。
  2. newHead = 蛇头 + 偏移（right 为 x+1，left 为 x-1，down 为 y+1，up 为 y-1）。
  3. 撞墙判定：newHead 不在墙内范围（x 在 1..width-2，y 在 1..height-2）→ 游戏结束。
  4. 自撞判定：newHead 与 `snake.slice(0, -1)` 中任一格相同 → 游戏结束。注意必须排除蛇尾：本步蛇尾会移走，不算碰撞。
  5. `snake.unshift(newHead)`。
  6. 若 newHead 等于食物：分数 +1，生成新食物（从空白格随机选，可用注入的随机源），不 pop 尾部。
  7. 否则 `snake.pop()` 移除尾部。

## 验收标准

- `node --test` 全部通过，至少覆盖：初始状态（长度、方向、棋盘尺寸）、四个方向移动、吃食物后增长与加分、撞墙结束、撞自己结束、180 度掉头被忽略、食物不会生成在蛇身上。
- `node simulate.js demo_inputs.txt` 能连续渲染多帧画面，最后打印"游戏结束"与总分并正常退出（退出码 0）。
- 浏览器打开 index.html 可用方向键或 W/A/S/D 游玩，空格暂停，R 重新开始。
